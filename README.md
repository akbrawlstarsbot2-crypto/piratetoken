# PirateToken GitHub Pages site

Upload `index.html`, `styles.css`, `config.js`, and `app.js` to the root of the `piratetoken-site` repository. Do not upload the EXE files to the repository; add them as assets in a GitHub Release instead.

After creating the GitHub Release, replace `YOUR-GITHUB-USERNAME` in `config.js` with your GitHub username, then commit the updated file.
